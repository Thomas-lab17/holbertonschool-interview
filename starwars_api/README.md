# Star Wars API

Print all character names of a Star Wars movie in order, using the Star Wars
API and the `request` module.

## Usage
```
./0-starwars_characters.js <Movie ID>
```

## File
- `0-starwars_characters.js`: fetches the film by ID and prints each character
  name, one per line, in the order of the film's `characters` list.
